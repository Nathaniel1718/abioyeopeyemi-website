Syntax Tree Drawer

Type labelled bracketing, or build the tree by hand: click a node to add a branch, drag branches to move them, and drop a branch on another node to re-attach it. Export as PNG, SVG, or a Word file with editable shapes.

e.g. [S [NP Adé] [VP [V jẹ] [NP iṣu]]] · ^ before a label draws a triangle · NP_1 gives a subscript · ->1 … <1> draws a movement arrow
Click a node to select it.

Build by hand

  • Click a node, then the gold + under it to add a branch.
  • Double-click a node to rename it.
  • Insert parent wraps a node in a new one (handy for adjunction).
  • Delete removes the selected branch.
  • Right-click (or long-press on a phone) a node, line or arrow for more options, including deleting it.

Move branches

  • Drag a node, or the line above it, to move it with everything under it.
  • Switch to Drag: single node to move one node only.
  • Drop a branch onto another node (it turns green) to attach it there.
  • Drag the empty canvas to pan; use + / −, the mouse wheel or pinch with two fingers to zoom.

Movement arrows

  • Select the node that moved (e.g. the trace), click Arrow, then click where it landed.
  • Drag an arrow up or down to change how deep it curves.
  • Click an arrow to select it; Delete removes it, Reverse flips it.
  • In brackets: ->1 after the moved item, <1> after its landing site, e.g. [NP_i <1> Adé] … [NP t_i ->1].

Brackets

  • [NP the dog]: words after a label form one leaf.
  • [^NP the big dog]: draws a triangle.
  • [NP_i ...] or t_i: subscripts.
  • The brackets update as you edit the tree, and the tree redraws as you type.
